## 🌟 Featured Projects

### 🏭 KairoX AI ERP — *Factory Operating System for Leather Garment Manufacturing*
> 🔒 Private / commercial product · Architect & backend lead

| 🧩 Highlights | ⚙️ Engineering |
|---|---|
| 📦 **12+ domain modules** — production, barcode, materials, employee, attendance, wages, clients, analytics, imports, intelligence | ⚡ **FastAPI + SQLAlchemy 2.0 async + Pydantic v2 + Alembic** |
| 🏷️ **Barcode lifecycle** for pieces, leather / lining / accessory lots and reusable drawers | 🐘 **Supabase PostgreSQL**, Redis & Celery workers |
| 🔄 **Production state machine** with 4-gate validation — `ROLE → SKILL → SEQUENCE → MERGE` | 🐳 **Docker** on **AWS EC2**, Nginx, Gunicorn + Uvicorn, HTTPS |
| ✅ **Audited approval transitions** for MD & client sign-off | 🧪 Async test suite, seed pipelines, documented runbooks |
| 🧠 **Coming next:** AI-driven BOM costing engine — DXF geometry + ML models + LLM layer (Gemini / Groq) | 🛡️ Role-based access & security-first design |

### 📞 AI Voice Agent — *Automated Collections Calling*
> 🔒 Client project · AI agents

- 🗣️ AI voice agents that **auto-dial borrowers**, hold natural conversations and **capture responses**
- 📝 Speech-to-text **transcription + structured storage** of every call
- 📊 **Client dashboard** for call outcomes & follow-ups, designed for **500+ calls/day**

### 🤝 AI CRM & Agent Platform
> 🔒 Internal product line
